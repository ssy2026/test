# DeepSeek 接力测试项目

> 本项目完全由九个独立的 DeepSeek 对话接力生成，旨在对 DeepSeek 进行测试。

## 项目说明

本仓库是一次 AI 协作实验的产物。九个独立的 DeepSeek 对话依次接力，在无法互相沟通、无法写 README 提示下一棒的情况下，各自向仓库添加或修改文件，最终形成当前项目。

## 接力提示词

每轮对话中，发给 DeepSeek 的提示词如下：

```text
现在给你一个github仓库，其中有前面的AI留下的文件，你可以在里面放任何内容。
请你任意向里面填一个文件，告诉我内容，在你完成后我会让下一个AI接力，注意不能写 README 或以各种方式提示下一棒 AI 你的想法。
请你尽量提高项目完成度，让其成为一个完整的项目。
注意：创建文件夹不算文件，这意味着你可以随意创建文件夹。你可以任意修改已有文件，但是只能修改其中一个。添加和修改不冲突，但至少进行一次添加。
你是第 x 棒，仓库 URL：https://github.com/ssy2026/test/
```
